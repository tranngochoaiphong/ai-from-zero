# AI From Zero (English)

*[← Back to language selection](../README.md) · [Tiếng Việt](../vi/README.md)*

A hands-on journey from knowing nothing about AI to building real things with it. Every topic is written in plain English, one lesson at a time, as I learn it.

This is a learning log, not a polished textbook. The goal is simple: read one lesson, do it the same day, move on.

---

## Who this is for

* You are new to AI and want a clear path instead of scattered tutorials.
* You can handle a computer and a terminal, but you are not expected to know machine learning.
* You learn best by doing, not just reading.

No prior AI experience is required. Each phase only assumes the one before it.

---

## How to use this repo

1. Start at the top of Phase 1 and work down in order.
2. Read one lesson, then actually run the steps in it before moving on.
3. When a phase ends, build the matching project in `projects/` to lock it in.
4. Keep the `resources/` folder open. The glossary and cheat-sheets are there to look things up fast.

Lessons are numbered so they always read in the right order.

---

## The roadmap

| Phase | Folder | What you can do after it |
|---|---|---|
| 1. Foundations | `01-foundations/` | Run AI on your own machine and understand what an LLM is |
| 2. Using models | `02-using-models/` | Talk to models well and call them from code |
| 3. Knowledge and data | `03-knowledge-and-data/` | Make a model answer using your own documents (RAG) |
| 4. Customizing models | `04-customizing-models/` | Fine-tune a model and run your own version |
| 5. Agents and automation | `05-agents-and-automation/` | Build models that take actions, not just answer |
| Projects | `projects/` | Combine everything into working apps |
