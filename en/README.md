# AI From Zero (English)

[Back to language selection](../README.md) | [Tiếng Việt](../vi/README.md)

A guide to building real things with AI, one lesson at a time, written in plain English.

This is a learning log, not a textbook. Read one lesson. Do the steps the same day. Then move on.

## Who this is for

* People new to AI who want a clear path instead of scattered tutorials.
* People who can use a computer and a terminal but do not know machine learning.
* People who learn by doing, not just reading.

Each phase assumes only the phase before it is done.

## How to use this repo

1. Start at the top of Phase 1 and work down in order.
2. Read one lesson, then run the steps before moving on.
3. At the end of a phase, build the matching project in `projects/` to lock in the knowledge.
4. Keep the `resources/` folder open. The glossary and cheat sheets are there for quick reference.

Lessons are numbered so they always read in the right order.

## The roadmap

| Phase | Folder | What it unlocks |
| --- | --- | --- |
| 1. Foundations | `01-foundations/` | Run AI on a local machine and understand what an LLM is |
| 2. Using models | `02-using-models/` | Talk to models effectively and call them from code |
| 3. Knowledge and data | `03-knowledge-and-data/` | Make a model answer from local documents (RAG) |
| 4. Customizing models | `04-customizing-models/` | Fine tune a model and run a custom version |
| 5. Agents and automation | `05-agents-and-automation/` | Build models that take actions, not just answer |
| Projects | `projects/` | Combine everything into working apps |

## Start here

Open the first lesson: [`01-foundations/01-running-ai-on-your-own-computer.md`](01-foundations/01-running-ai-on-your-own-computer.md)

It walks through running a first AI model locally, with no account and no cost.
